# Prototipo fotográfico descartado

Estos PNG pertenecen a la iteración anterior, rechazada por el usuario porque los vehículos eran imágenes planas. Se conservan únicamente como historial de diseño, fuera de la carpeta pública y del despliegue web.

La escena activa usa geometría Three.js: una moto compartida por ambos pilotos y dos tipos de tráfico, bajo cielo cubierto y sobre asfalto seco.
